Detection Methodology & Scientific Transparency

FinOps Principles

CloudGuard AI utilizes a robust non-parametric statistical method based on the Rolling Median and Median Absolute Deviation (MAD):

  • Outlier Resistance: Unlike classical mean and standard deviation, median and MAD are unaffected by prior spikes, preventing the baseline from distorting during high-spend periods.
  • Modified Z-Score: Evaluated using the standard formula: 0.6745 × (Actual - Median) / MAD.
  • Data Sufficiency Rules: Requires at least 5 consecutive historical days before establishing a baseline to prevent false alerts on newly provisioned services.
  • Disclaimers: Statistical deviations indicate uncharacteristic consumption patterns. They do not constitute conclusive evidence of billing errors, fraud, or waste without inspection in your cloud provider's console.

🛡️ Privacy Architecture & Guarantees

Static Hosting (GitHub Pages)
  • 🔒 100% In-Browser Execution: Your cloud billing files are parsed directly inside your browser memory using Papa Parse and Web APIs. Zero bytes are uploaded to any external server.
  • 🚫 No External Analytics or Trackers: This application contains no tracking scripts, telemetry, cookies, or paid API calls.
  • 🔑 Zero Secrets or Credentials: CloudGuard AI operates solely on static billing CSV exports. It never asks for, requires, or stores AWS/GCP/Azure access keys or passwords.
  • 🌐 Static GitHub Pages Deployment: Hosted as pure static HTML5/CSS/JavaScript. GitHub Pages acts purely as a static content distributor.
